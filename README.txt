CWordStack v1.0.0

WordStack의 학습 구조를 중국어 학습용으로 전환한 개인용 PWA입니다.

주요 데이터 필드
ChineseWord | Pinyin | PartOfSpeech | ChineseExample | KoreanMeaning | KoreanExample | Category | Chapter | Tags

주요 기능
- 단어장/챕터 기반 플래시카드
- 좌우 스와이프, 앞뒤 전환, 모름/암기완료
- 중국어/한국어 TTS, 3초 반복 재생
- SM-2형 간격반복
- 취약단어
- 일반퀴즈
- KR/CN 양방향 암기퀴즈
- 2~10초 발화 간격 설정
- 통계
- Excel 가져오기/내보내기
- Google Sheets 양방향 동기화
- JSON 백업/복원
- GitHub Pages 정적 배포

CWordStack은 기존 WordStack과 다른 localStorage 키를 사용하므로 동일 기기에서 데이터가 섞이지 않습니다.
